## 📌 Overview

This project presents an interactive **Sales Analysis Dashboard** built in Microsoft Excel to analyze business performance across revenue, orders, customer behavior, and delivery efficiency.

The dashboard transforms raw sales data into meaningful insights using dynamic charts, KPIs, and slicers, enabling quick and informed decision-making.

---

## 🎯 Key Metrics

* **Total Orders:** 1,000
* **Total Revenue:** ₹35,20,984
* **Average Customer Spend:** ₹3,520.98
* **Average Delivery Time:** 5.53 days

---

## 📈 Dashboard Features

### 🔹 Revenue Analysis

* Revenue by **Occasion** (Anniversary, Birthday, Diwali, Holi, etc.)
* Revenue by **Product Category** (Sweets, Colors, Soft Toys, etc.)
* Revenue trends by **Month**

### 🔹 Sales Trends

* Revenue distribution by **Order Time (Hour-wise)**
* Identification of **peak sales hours**

### 🔹 Product Insights

* Top 5 **Best-Selling Products** by revenue

### 🔹 Geographic Insights

* Top 10 **Cities by Order Volume**

### 🔹 Filters & Interactivity

* Slicers for:

  * Order Date
  * Delivery Date
  * Occasion
* Dynamic filtering for real-time analysis

## 💡 Key Insights

* Occasion-based events significantly drive revenue.
* Categories like **Sweets** and **Colors** are top contributors.
* Seasonal spikes observed during key months.
* Certain cities consistently generate higher order volumes.
* Customer purchase behavior shows time-based trends.

## 🚀 How to Use

1. Download the Excel file from this repository.
2. Open in Microsoft Excel (recommended version: 2016 or later).
3. Use slicers to filter data by date and occasion.
4. Explore charts and KPIs for insights.
